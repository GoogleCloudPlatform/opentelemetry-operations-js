# OpenTelemetry Operations Exporter Samples for JavaScript

This directory contains code samples demonstrating how to use the Google Cloud exporters provided in this repository:

* [metrics](./metrics): Using `@google-cloud/opentelemetry-cloud-monitoring-exporter` to export metrics to Google Cloud Monitoring.
* [trace](./trace): Using `@google-cloud/opentelemetry-cloud-trace-exporter` to export traces to Google Cloud Trace.

## Migrated Samples

Other general OpenTelemetry JavaScript samples (including auto-instrumentation quickstart, OTLP metric export, and OTLP trace export) have been migrated to [GoogleCloudPlatform/opentelemetry-samples](https://github.com/GoogleCloudPlatform/opentelemetry-samples/tree/main/javascript):
